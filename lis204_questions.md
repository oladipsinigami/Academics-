### QUESTION 01
Type: Essay
Category: Compulsory Class Assignment
Text: (a) MIS in Academic Library Decision-Making: Analyze how a Management Information System (MIS) assists library managers and university archivists in making evidence-based administrative decisions regarding budget allocation, collection usage, and staffing.
(b) Case Study — FUTA Library (Albert Ilemobade Library): Critically evaluate the practical operational impact of implementing a modern MIS in an academic technology library such as the Federal University of Technology, Akure (FUTA) Library. Highlight improvements in circulation metrics, serials management, and electronic resource tracking.
(c) MIS vs. Library Automation System: Differentiate clearly between a Library Automation System (e.g., Koha, Voyager ILS) and a Management Information System (MIS) in an academic library setting. Explain why automating library routines does not automatically constitute an MIS unless analytical decision-support tools are embedded.
(d) Strategic Planning Process for MIS: Outline the sequential phases of the Strategic Information System Planning (SISP) process in designing an MIS for a university library, detailing the factors (corporate changes, competitive opportunities/threats, and system evolution) that initiate SISP.
Model Answer: (a) A Management Information System (MIS) transforms raw library transactional data (circulation counts, OPAC search logs, gateway turns, e-journal downloads) into actionable managerial intelligence. It assists library managers and archivists by optimizing resource allocation, collection development, and staff deployment.
(b) At FUTA Library (Albert Ilemobade Library), an integrated MIS enables automated tracking of e-resource databases (IEEE Xplore, ScienceDirect), predictive circulation management for high-demand textbooks, and download analytics for faculty publications in the institutional repository.
(c) A Library Automation System (ILS) handles routine operational transactions (checkout, cataloging). An MIS synthesizes operational data into executive summary reports and decision support for leadership.
(d) SISP is a top-down planning process initiated by corporate changes, external opportunities/threats, and system evolution. Its phases include: 1. Analyzing organizational objectives; 2. Assessing current IT infrastructure; 3. Formulating MIS architecture; 4. Implementation roadmap and evaluation.

### QUESTION 02
Type: Essay
Category: Methodology
Text: (a) Classroom Interaction Questions: In class, the lecturer raised two fundamental questions regarding Information System Development (ISD) methods:
i. Why are local methods developed?
ii. Are textbook methods actually used in practice?
Evaluate the contradiction between textbook ISD methods and real-world practice in library automation, explaining why academic libraries frequently modify standard methods or develop proprietary local methods.
(b) Tacit Method Knowledge: Define Tacit Method Knowledge in the context of library information system development. Explain how reflection-in-action, intuition, and technical rationality influence system development.
(c) Degrees of Method Modification: Explain the three (3) evaluated degrees of method modification in library MIS:
1. Selection path within a method (Modification Exemplifier - ME)
2. Combination of methods for internal use
3. Organization of locally developed proprietary methods
Model Answer: (a) Textbook ISD methods assume rigid, linear development paths, whereas real-world library automation requires flexible, localized adaptations to unique workflows, institutional constraints, and legacy data structures. Libraries develop local methods to fill gaps left by generic textbook frameworks.
(b) Tacit Method Knowledge is the experiential, intuitive understanding developed by systems librarians and developers through practice, reflection-in-action, and practical problem-solving rather than formal textbook manuals.
(c) 1. Selection path: Selecting specific subsets/phases of an established method. 2. Combination: Blending features of multiple methods to create a hybrid internal framework. 3. Proprietary local methods: Engineering custom, localized development procedures built specifically for the institution.

### QUESTION 03
Type: Essay
Category: Management Structure
Text: (a) Four Functional Types of MIS: Define and compare the four (4) functional types/levels of MIS described in the lecture notes:
1. Data Bank Management Information System (DMIS)
2. Predictive Management Information System
3. Decision-Taking Management Information System
4. Decision-Making Management Information System
(b) Library Management Hierarchy & Roles: Outline the 3-tier Library Management Hierarchy (Top Management, Middle Management, Operational/Lower Level), detailing specific staff titles, responsibilities, and functions across each tier.
(c) Communication Mechanics: Analyze the downward, upward, and horizontal communication flows required between these management levels to ensure strategic library goals are achieved without bottlenecking.
Model Answer: (a) DMIS: Centralized database storage of basic records. Predictive MIS: Uses historical data and statistical models to project future trends. Decision-Taking MIS: Programmed system that automatically executes decisions based on predefined rules (e.g. locking patron accounts when fine limits are reached). Decision-Making MIS: Evaluates multi-criteria options and presents strategic recommendations for human executive selection.
(b) Top Management (University Librarian, Deputy Librarians): Strategic planning, policy formulation, budget defense. Middle Management (Heads of Units - Reference, Serials, Cataloging): Operationalizing policies, unit supervision, resource requests. Operational Level (Library Officers, Assistants, Porters): Daily routine execution (charging, shelving, patron assistance).
(c) Downward communication conveys administrative goals and directives; Upward communication delivers operational reports, feedback, and resource requests; Horizontal communication ensures inter-departmental synergy between technical, circulation, and IT units.

### QUESTION 04
Type: Essay
Category: IT Ethos
Text: Explain the three (3) core pillars of the Ethos of Information Technology in library operations:
1. Complexity: The internal architecture and system designer specifications of library IT.
2. Speed: The storage, retrieval, and transmission capabilities for massive digital collections.
3. Predictability: Why information technology is inherently less predictable and reliable when compared to traditional pervasive utilities (electricity, automobiles, television), and how library managers mitigate system downtime.
Model Answer: 1. Complexity: Refers to the multi-layered technical infrastructure, network protocols, database schemas, and MARC/Dublin Core metadata standards powering library systems.
2. Speed: The rapid processing capability for indexing millions of bibliographic records, instant search queries, and high-speed digital document transmission.
3. Predictability: IT systems are prone to software bugs, server crashes, cyber threats, and network outages, making them less predictable than physical utilities. Managers mitigate this via automated backups, cloud redundancy, disaster recovery plans, and maintenance SLA protocols.

### QUESTION 05
Type: Essay
Category: 2024/2025 Semester Examination (Section A)
Text: (a) Discuss the term "Management Information System" (MIS)? (10 marks)
(b) Discuss the role of Management Information System to Albert Ilemobade Library, Federal University of Technology, Akure (FUTA), Akure. (10 marks)
Model Answer: (a) A Management Information System (MIS) is a structured, computer-based system that collects, processes, stores, synthesizes, and presents quantitative and qualitative operational data from various organizational units into timely, structured, and actionable information. It provides executive summaries, performance metrics, and decision-support tools for managers to plan, control, evaluate, and direct organizational activities efficiently.

(b) At the Albert Ilemobade Library, FUTA, an MIS plays pivotal roles: (1) Evidence-Based Decision Making: Analyzes circulation trends and gate counts to guide collection development and acquisitions (e.g. allocating budgets toward high-demand engineering and technology e-resources); (2) Serials & E-Resource Tracking: Monitors database usage metrics (e.g. IEEE Xplore, ScienceDirect downloads) to justify renewal subscriptions; (3) Operational Efficiency & Automation: Streamlines Koha ILS transactions, cataloguing throughput, and patron registration; (4) Strategic Resource Allocation: Optimizes library staff deployment during peak study hours and manages hardware maintenance cycles across computer laboratories and study carrels.

### QUESTION 06
Type: Essay
Category: 2024/2025 Semester Examination (Section A)
Text: (a) Explicate the three (3) levels of Management in relation to a Library Setting. (10 marks)
(b) Juxtapose the term "Ethics of Information Technology". (10 marks)
Model Answer: (a) The 3-tier Management Structure in a Library:
1. Top-Level Management (Strategic Tier - University Librarian, Deputy Librarians): Focuses on long-range strategic planning, policy formulation, institutional budget defense, inter-library collaboration, and overall governance.
2. Middle-Level Management (Tactical Tier - Heads of Departments/Units: Cataloging, Circulation, Serials, Readers' Services, Systems/IT): Translates strategic goals into operational plans, supervises unit staff, coordinates workflow schedules, and submits evaluation reports to executive leadership.
3. Lower-Level / Operational Management (Supervisory Tier - Principal/Senior Library Officers, Library Assistants, Technical Assistants): Manages day-to-day routine tasks, direct patron assistance, shelf reading, charging/discharging books, data entry, and basic system troubleshooting.

(b) Ethics of Information Technology in libraries involves the moral principles, professional standards, and legal frameworks governing the responsible use, management, and dissemination of technology and digital information. Key dimensions include: (1) User Privacy & Data Protection: Safeguarding patron search histories, circulation logs, and personal data from unauthorized access; (2) Intellectual Property & Copyright Compliance: Balancing fair use access with digital rights management (DRM) for electronic journals and books; (3) Equitable Access vs. Digital Divide: Preventing algorithmic bias and ensuring digital resources are accessible to all patrons including disabled users; (4) Information Integrity: Ensuring data stored in institutional repositories is authentic, uncorrupted, and plagiarism-free.

### QUESTION 07
Type: Essay
Category: 2024/2025 Semester Examination (Section B)
Text: (a) Discuss the application of IT in Information Management Systems. (10 marks)
(b) Explain the following IT tools and communication channels: (10 marks)
i. Electronic Mail (2 marks)
ii. Teletext (2 marks)
iii. Fax (Facsimile) (2 marks)
iv. Bulletin Board System (BBS) (2 marks)
v. Teleconferencing (2 marks)
Model Answer: (a) IT applications transform Information Management Systems by enabling high-speed processing, massive storage capacity, seamless database networking, and real-time retrieval. In library information management, IT facilitates automated cataloguing (MARC21/Z39.50), digital repository management (DSpace), Web-OPAC search engines, automated circulation (barcode/RFID), and cloud-based inter-library document delivery systems.

(b) i. Electronic Mail (E-mail): A digital telecommunication service allowing instant transmission of messages, documents, and reference queries between computer users across local networks or the Internet.
ii. Teletext: A television-based broadcast information retrieval system that transmits text and graphic pages via television signals to display news, announcements, and index data on compatible TV monitors.
iii. Fax (Facsimile): A telecommunication technology that scans printed text/images and transmits the scanned document over telephone lines to print an identical physical copy at the receiving terminal.
iv. Bulletin Board System (BBS): A computer server system running software that allows users to connect, upload/download files, read news bulletins, and post messages on public message boards.
v. Teleconferencing: An interactive audio or video telecommunications session linking multiple participants in geographically dispersed locations for live meetings, virtual lectures, and collaborative discussions.

### QUESTION 08
Type: Essay
Category: 2024/2025 Semester Examination (Section B)
Text: Discuss the word "Internet" explicitly, detailing its architectural foundation, core protocol suites (TCP/IP), services, and strategic impact on academic library operations. (20 marks)
Model Answer: The Internet is a globally interconnected network of networks utilizing standardized communication protocols to link billions of computers, servers, and digital devices worldwide. Core aspects:
1. TCP/IP Architecture: Operates on Transmission Control Protocol (TCP) which breaks data into packets and ensures reliable packet transmission, and Internet Protocol (IP) which routes packets to unique destination IP addresses.
2. Core Internet Services: World Wide Web (HTTP/HTTPS) for web navigation, Domain Name System (DNS) for translating human-readable URLs to IP addresses, File Transfer Protocol (FTP/SFTP) for file exchange, and E-mail (SMTP/IMAP).
3. Strategic Impact on Academic Libraries: (1) 24/7 Access to Digital Holdings: Enables remote access to Web-OPACs, institutional repositories, and subscription databases (EBSCOhost, JSTOR); (2) Virtual Reference & Document Delivery: Facilitates digital reference helpdesk via email, chat, and electronic document delivery; (3) Inter-Library Resource Sharing: Connects libraries globally for cooperative cataloguing, shared consortia subscriptions, and electronic document exchange.

### QUESTION 09
Type: Essay
Category: 2024/2025 Semester Examination (Section B)
Text: Describe five (5) examples of storage devices used in library information systems, categorizing them into primary, secondary, and optical/cloud media. (20 marks)
Model Answer: Five key storage devices utilized in modern library IT environments:
1. Random Access Memory (RAM) [Primary Volatile Storage]: High-speed semiconductor memory directly accessed by the CPU to temporarily hold active operating system files, Koha database queries, and running applications. Data is lost upon power off.
2. Hard Disk Drives (HDD) [Secondary Magnetic Storage]: High-capacity magnetic storage devices containing spinning magnetic platters used in library servers to store main operating systems, large bibliographic databases, and local archival backups permanently.
3. Solid State Drives (SSD) [Secondary Flash Storage]: High-performance storage devices using non-volatile flash memory microchips with no moving mechanical parts. Used in Web-OPAC servers and database host machines to provide ultra-fast read/write speeds for user searches.
4. Optical Discs (CD-ROM / DVD-ROM / Blu-ray) [Removable Optical Storage]: Storage media read using laser light technology. Historically used in libraries to distribute standalone reference encyclopedias, digitized historical archives, and educational video collections.
5. Storage Area Networks (SAN) / Cloud Storage [Enterprise Networked Storage]: High-speed network-attached storage arrays or remote cloud storage infrastructure (e.g. AWS S3, Google Cloud Storage) used by academic libraries to back up massive digital repositories, institutional research data, and digitized manuscripts with high redundancy.
